ChatGPT Clone (My Chatbot)

A conversational AI chatbot built with Next.js, TailwindCSS, and AI SDKs.
It allows users to interact with an AI assistant in real time, similar to ChatGPT.

🚀 Features

💬 Real-time chatbot conversation interface

🎨 Modern UI with TailwindCSS + shadcn/ui components

🔄 State management with Zustand

🤖 Powered by AI SDKs (@ai-sdk/openai, @ai-sdk/google)

🌐 Deployed on Vercel

🛠️ Tech Stack

Frontend: Next.js, React, TailwindCSS

AI: AI SDK (OpenAI / Google)

State Management: Zustand

Deployment: Vercel

📦 Installation & Setup

Clone the repo:

git clone https://github.com/Anangsha072/ChatGpt.git
cd ChatGpt/my-app


Install dependencies:

pnpm install


Create a .env.local file in the root (my-app/) and add:


GOOGLE_API_KEY=your_google_api_key


Run locally:

npm run dev


App will be live at http://localhost:3000.

🌍 Deployment

Deployed using vercel
to view the chatgpt visit -> https://chat-gpt-roxm.vercel.app/

Steps:

1. Push code to GitHub.

2. Connect the repo on Vercel


3. Set Root Directory = my-app in project settings.

4. Add environment variables (API keys) in Vercel dashboard.

5. deploy.
